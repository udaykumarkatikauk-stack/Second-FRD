## Understanding of the Requirement

This project is about creating a Java program to check a person's health details. The program calculates BMI, finds the BMI category, checks activity, water intake, and sleep hours, and displays the overall fitness status with a message.

## Hard-coded Values Selected

The program uses hard-coded values for name, age, height, weight, activity hours, water intake, and sleep hours. Two profiles are used for testing.

## Variables and Data Types Planned

* `String` for name and status messages.
* `int` for age, activity hours, sleep hours, and rounded BMI.
* `double` for height, weight, water intake, and BMI.

## Outputs Expected

The program displays:

* Name
* BMI value
* BMI category
* Activity status
* Water intake status
* Sleep status
* Overall fitness status
* Improvement message

## Arithmetic Operators Planned

Arithmetic operators are used to calculate BMI.

## Assignment Operators Planned

The assignment operator (`=`) is used to assign values to variables.

## Relational Operators Planned

Relational operators (`<`, `>`, `<=`, `>=`) are used to compare BMI and health values.

## Logical Operators Planned

The logical AND operator (`&&`) is used to check multiple health conditions together.

## Unary Operators Planned

The increment operator (`++`) is used in the loop to move to the next profile.

## Ternary Operator Usage

The ternary operator is used to decide whether the activity status is good or needs improvement.

## Conditions Required

`if`, `else if`, and `else` statements are used to determine BMI category, health status, and improvement message.

## Loop Selected

A `while` loop is used.

## Reason for Selecting the Loop

The `while` loop is used because the requirement asks to evaluate at least two profiles.

## Validation Rules

The program checks the BMI range, activity hours, water intake, and sleep hours before deciding the overall fitness status.

## Test Value Sets Planned

Two different hard-coded profiles are used to test the program and verify that the output is correct.
